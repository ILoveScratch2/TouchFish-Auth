# Contributing to TouchFish Auth

Thank you for considering contributing to TouchFish Auth! We welcome contributions from the community to help improve the project. Here are some guidelines to follow when contributing:

## Reporting Issues

- Check the [issue tracker](https://github.com/ILoveScratch2/touchfish-auth/issues) to see if your issue has already been reported.
- Provide a clear and descriptive title and description for the issue.
- Include steps to reproduce the issue, if applicable.

## Submitting Pull Requests

- Fork the repository and create a new branch for your feature or bugfix.
- Ensure your code follows the existing style and conventions.
- Include tests for any new functionality.
- Update the documentation if necessary.
- Submit a pull request with a clear description of your changes.

## Code of Conduct

By contributing to this project, you agree to abide by the [Code of Conduct](CODE_OF_CONDUCT.md).
